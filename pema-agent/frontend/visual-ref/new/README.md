# visual-ref/new: screenshots of the new app

Generated by `pnpm visual` (git-ignored; only this README is committed).

```
pnpm dev:mock          # mock backend + next dev, in one shell
pnpm visual            # in another shell
```

Environment: `VISUAL_BASE_URL` (default `http://localhost:3000`), `VISUAL_ROLE` (default `owner`),
`VISUAL_ROUTES=/today,/patients`, `VISUAL_VIEWPORTS=1920x1020,390x844`, `VISUAL_SCHEME=dark` (dark-mode shots, `-dark`
suffix). In Git Bash on Windows prefix the command with `MSYS_NO_PATHCONV=1`, or the shell rewrites `/today`.

It enumerates `src/app/**/page.tsx` (leaving out `/dev/*` and `/login`), signs in against the mock backend with
a synthetic user, and takes one screenshot per route and viewport as `<viewport>-<route>.png`. The five
viewports are 1920x1020, 1440x900, 1280x720, 1024x768 and 390x844. `summary.json` lists every screen with its
horizontal overflow in pixels (`document.scrollWidth - window.innerWidth`), HTTP status and page errors. The
exit code is 1 when any screen overflows, answers 4xx/5xx or logs a page error.

Compare with `../old/` (see its README).
