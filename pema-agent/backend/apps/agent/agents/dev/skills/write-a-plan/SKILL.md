---
name: write-a-plan
description: Turn a multi-step request into a short numbered plan before doing it.
---

1. Restate the goal in one sentence.
2. List the steps in order, one line each; mark the steps that need a tool.
3. Name anything you still need from the user and ask for it first.
4. Do the steps; after each one, say in a few words what changed.
