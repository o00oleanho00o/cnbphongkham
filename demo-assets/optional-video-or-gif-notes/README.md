# Ghi hình demo

Không có video được dựng sẵn. Có thể quay trực tiếp theo `docs/16_DEMO_SCRIPT.md` sau khi chạy app bằng lệnh trong README ở workspace root. Screenshot thật và bằng chứng kiểm thử được lưu trong `demo-assets/screenshots/` và `demo-assets/test-results/`.

Đặt cửa sổ Clinic ở desktop và mở Patient Mobile ở tab cùng trình duyệt/cùng origin để chia sẻ trạng thái demo. Không nhập thông tin hay ảnh bệnh nhân thật.
