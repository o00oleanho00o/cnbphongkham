# PEMA DIGITAL CLINIC — ULTRA PACKAGE

Package này được thiết kế để chạy **1 section Ultra duy nhất**.

## Cách chạy

1. Tạo/open một workspace/repo mới cho nghiên cứu này.
2. Upload toàn bộ file zip này cho Codex/Ultra hoặc giải nén vào repo.
3. Paste nguyên nội dung file `START_PROMPT.txt`.
4. Cho Ultra chạy end-to-end.
5. Không chia prompt thành nhiều section trừ khi hệ thống bắt buộc.
