# I4 · Đặt lịch hẹn

Nhóm **I · Vận hành Clinic · bổ sung từ web** · màn chi tiết · trạng thái: **đã port**

> Web › dialog đặt lịch · chọn dịch vụ, bác sĩ, phòng trước khi chọn giờ

## Nguồn logic
- Web: dialog đặt lịch · chọn dịch vụ, bác sĩ, phòng trước khi chọn giờ
- Web-only: logic port từ `prototype/shared/*.js` vào domain `shared/clinic` (`ClinicStore`, lệnh `transact`, lỗi `ClinicError` giữ câu tiếng Việt của web).
- Quyền theo `prototype/shared/staff-context.js` (`pages` + `capabilities`) → `Session.allows` + `session.staffContext().can(...)`.
- Web `operations-ui.js` › booking dialog; `ClinicStore.validate` / `saveAppointment` (câu lỗi của web).

## KMP
- Route: `Routes.AppointmentForm` ("appointment-form") · app bar "Đặt lịch hẹn"
- Composable: `AppointmentFormScreen` — `pema-kmp/feature/operations/src/commonMain/kotlin/com/pema/clinic/feature/operations/OperationsGraph.kt`
- Graph đăng ký: `operationsGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `addDays`, `block`, `clearPreparedCrmBooking`, `crmQueue`, `initials`, `minutes`, `money`, `patient`, `preparedCrmBookingInput`, `reception`, `saveAppointment`, `staffContext`, `time`, `updateService`, `validate`, `viDate`
- Shot test: `pema-kmp/feature/operations/src/jvmTest/kotlin/com/pema/clinic/feature/operations/OperationsShotTest.kt:35` → `pema-kmp/feature/operations/build/shots/I4-vs.png`
- Ảnh canvas: `pema-kmp/design-ref/I4.png`

- Lối vào: mục "Vận hành phòng khám" ở cuối màn chính của vai trò (lọc theo quyền).
