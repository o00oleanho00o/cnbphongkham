# K3 · Hành trình · cập nhật

Nhóm **K · Pema Care · bổ sung từ web** · tab "Hành trình" (Care) · trạng thái: **đã port**

> Web › patient-mobile › journey · thêm dòng thời gian cập nhật gần đây

## Nguồn logic
- Web: patient-mobile › journey · thêm dòng thời gian cập nhật gần đây
- Web `prototype/patient-mobile` + `prototype/shared/patient.js`.
- Web `patient.js` › journey(); `patientJourneyTimeline(patient)`.

## KMP
- Route: `Routes.Workspace` ("workspace") · app bar "Không gian làm việc"
- Composable: `WorkspaceScreen` — `pema-kmp/feature/workspace/src/commonMain/kotlin/com/pema/clinic/feature/workspace/WorkspaceGraph.kt`
- Graph đăng ký: `workspaceGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `patientJourneyTimeline`
- Shot test: `pema-kmp/feature/workspace/src/jvmTest/kotlin/com/pema/clinic/feature/workspace/WorkspaceShotsTest.kt:136` → `pema-kmp/feature/workspace/build/shots/K3-vs.png`
- Ảnh canvas: `pema-kmp/design-ref/K3.png`
