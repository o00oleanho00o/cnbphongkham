# I10 · Thu ngân · hóa đơn

Nhóm **I · Vận hành Clinic · bổ sung từ web** · màn chi tiết · trạng thái: **đã port**

> Web › cashier · danh sách hóa đơn toàn phòng khám, lọc còn phải thu

## Nguồn logic
- Web: cashier · danh sách hóa đơn toàn phòng khám, lọc còn phải thu
- Web-only: logic port từ `prototype/shared/*.js` vào domain `shared/clinic` (`ClinicStore`, lệnh `transact`, lỗi `ClinicError` giữ câu tiếng Việt của web).
- Quyền theo `prototype/shared/staff-context.js` (`pages` + `capabilities`) → `Session.allows` + `session.staffContext().can(...)`.
- Web `operations-ui.js` › cashier(): mọi hóa đơn toàn phòng khám, lọc Còn phải thu / Đã thanh toán.

## KMP
- Route: `Routes.CashierInvoices` ("cashier-invoices") · app bar "Thu ngân · hóa đơn"
- Composable: `InvoiceCashierScreen` — `pema-kmp/feature/billing/src/commonMain/kotlin/com/pema/clinic/feature/billing/InvoiceCashier.kt`
- Graph đăng ký: `invoiceCashierGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `money`, `pay`, `staffContext`
- Shot test: `pema-kmp/feature/billing/src/jvmTest/kotlin/com/pema/clinic/feature/billing/InvoiceCashierShotTest.kt:13` → `pema-kmp/feature/billing/build/shots/I10-vs.png`
