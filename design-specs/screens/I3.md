# I3 · Điều phối theo phòng

Nhóm **I · Vận hành Clinic · bổ sung từ web** · màn chi tiết · trạng thái: **đã port**

> Web › schedule · lưới phòng × giờ thành danh sách theo phòng; kéo-thả chỉ có trên web

## Nguồn logic
- Web: schedule · lưới phòng × giờ thành danh sách theo phòng; kéo-thả chỉ có trên web
- Web-only: logic port từ `prototype/shared/*.js` vào domain `shared/clinic` (`ClinicStore`, lệnh `transact`, lỗi `ClinicError` giữ câu tiếng Việt của web).
- Quyền theo `prototype/shared/staff-context.js` (`pages` + `capabilities`) → `Session.allows` + `session.staffContext().can(...)`.
- Web `operations-ui.js` › schedule(): lịch theo phòng, đệm chuẩn bị, waitlist, khóa phòng.

## KMP
- Route: `Routes.RoomSchedule` ("room-schedule") · app bar "Điều phối theo phòng"
- Composable: `RoomScheduleScreen` — `pema-kmp/feature/operations/src/commonMain/kotlin/com/pema/clinic/feature/operations/OperationsGraph.kt`
- Graph đăng ký: `operationsGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `addDays`, `block`, `clearPreparedCrmBooking`, `crmQueue`, `initials`, `minutes`, `money`, `patient`, `preparedCrmBookingInput`, `reception`, `saveAppointment`, `staffContext`, `time`, `updateService`, `validate`, `viDate`
- Shot test: `pema-kmp/feature/operations/src/jvmTest/kotlin/com/pema/clinic/feature/operations/OperationsShotTest.kt:28` → `pema-kmp/feature/operations/build/shots/I3-vs.png`
- Ảnh canvas: `pema-kmp/design-ref/I3.png`
