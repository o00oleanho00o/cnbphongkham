# I7 · Ảnh trước / sau

Nhóm **I · Vận hành Clinic · bổ sung từ web** · màn chi tiết · trạng thái: **đã port**

> Web › studio · chọn góc chụp, so sánh cùng view; không tự căn chỉnh hay chấm hiệu quả

## Nguồn logic
- Web: studio · chọn góc chụp, so sánh cùng view; không tự căn chỉnh hay chấm hiệu quả
- Web-only: logic port từ `prototype/shared/*.js` vào domain `shared/clinic` (`ClinicStore`, lệnh `transact`, lỗi `ClinicError` giữ câu tiếng Việt của web).
- Quyền theo `prototype/shared/staff-context.js` (`pages` + `capabilities`) → `Session.allows` + `session.staffContext().can(...)`.
- Web `clinic.js` › studio() + photos(p): ảnh thật = buổi điều trị có `image` cùng góc chụp; đầu = Trước, cuối = Sau; không có → ảnh minh họa.

## KMP
- Route: `Routes.PhotoStudio` ("photo-studio") · app bar "Ảnh trước / sau"
- Composable: `PhotoStudioScreen` — `pema-kmp/feature/patients/src/commonMain/kotlin/com/pema/clinic/feature/patients/ClinicToolsScreens.kt`
- Graph đăng ký: `clinicToolsGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `createPatient`, `daysBetween`, `patient`, `viDate`
- Shot test: `pema-kmp/feature/patients/src/jvmTest/kotlin/com/pema/clinic/feature/patients/ClinicToolsShotTest.kt:27` → `pema-kmp/feature/patients/build/shots/I7-vs.png`
