# I6 · Follow-up Inbox

Nhóm **I · Vận hành Clinic · bổ sung từ web** · màn chi tiết · trạng thái: **đã port**

> Web › followups · lọc Ảnh / Triệu chứng / Quá hạn, mỗi mục có người được giao

## Nguồn logic
- Web: followups · lọc Ảnh / Triệu chứng / Quá hạn, mỗi mục có người được giao
- Web-only: logic port từ `prototype/shared/*.js` vào domain `shared/clinic` (`ClinicStore`, lệnh `transact`, lỗi `ClinicError` giữ câu tiếng Việt của web).
- Quyền theo `prototype/shared/staff-context.js` (`pages` + `capabilities`) → `Session.allows` + `session.staffContext().can(...)`.
- Web `clinic.js` › followups(): lọc Ảnh / Triệu chứng / Quá hạn; doctor chỉ thấy hồ sơ mình (`owns`).

## KMP
- Route: `Routes.FollowUpInbox` ("follow-up-inbox") · app bar "Follow-up Inbox"
- Composable: `FollowUpInboxScreen` — `pema-kmp/feature/aftercare/src/commonMain/kotlin/com/pema/clinic/feature/aftercare/FollowUpInbox.kt`
- Graph đăng ký: `followUpInboxGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `patient`, `staffContext`
- Shot test: `pema-kmp/feature/aftercare/src/jvmTest/kotlin/com/pema/clinic/feature/aftercare/FollowUpInboxShotTest.kt:13` → `pema-kmp/feature/aftercare/build/shots/I6-vs.png`
