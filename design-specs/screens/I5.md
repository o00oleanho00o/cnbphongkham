# I5 · Hồ sơ mới

Nhóm **I · Vận hành Clinic · bổ sung từ web** · màn chi tiết · trạng thái: **đã port**

> Web › patients › Hồ sơ mới · tìm trước khi tạo để tránh chia lịch sử

## Nguồn logic
- Web: patients › Hồ sơ mới · tìm trước khi tạo để tránh chia lịch sử
- Web-only: logic port từ `prototype/shared/*.js` vào domain `shared/clinic` (`ClinicStore`, lệnh `transact`, lỗi `ClinicError` giữ câu tiếng Việt của web).
- Quyền theo `prototype/shared/staff-context.js` (`pages` + `capabilities`) → `Session.allows` + `session.staffContext().can(...)`.
- Web `clinic.js` › patients() › Hồ sơ mới; lệnh `createPatient` (ClinicToolsCommands) đồng bộ cả `MutableCatalogRepository` để hồ sơ mới hiện trong tìm kiếm.

## KMP
- Route: `Routes.NewPatient` ("new-patient") · app bar "Hồ sơ mới"
- Composable: `NewPatientScreen` — `pema-kmp/feature/patients/src/commonMain/kotlin/com/pema/clinic/feature/patients/ClinicToolsScreens.kt`
- Graph đăng ký: `clinicToolsGraph`
- Hàm domain `shared/clinic` import trong file (dùng chung cho mọi màn cùng file): `createPatient`, `daysBetween`, `patient`, `viDate`
- Shot test: `pema-kmp/feature/patients/src/jvmTest/kotlin/com/pema/clinic/feature/patients/ClinicToolsShotTest.kt:13` → `pema-kmp/feature/patients/build/shots/I5-vs.png`
